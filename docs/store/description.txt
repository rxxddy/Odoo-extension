UI Enhancer for Odoo — Chrome Web Store description
====================================================

=== English (en) ===
Make Odoo look and work the way you want.

UI Enhancer restyles the Odoo home screen and adds everyday tools for people who live in Odoo: consultants, developers and power users. Works with Odoo 16 to 19, on odoo.com, odoo.sh and your own servers.

BACKDROPS
• Animated effects: aurora, synth grid, nebula, dots, scanlines, in any two colours
• Plain colour or gradient, your own photo or a looping video
• Darken and blur to keep icons readable

APP ICONS
• Frame styles: liquid glass, void, chrome, titanium, porcelain, obsidian, carbon
• Smooth hover motion: levitate, magnet, tilt, focus, glide
• Boot animation, shape, size, and caption colour, size and font

LOGOS
• Place any number of logos over your backdrop

WORKSPACE
• PROD / STAGING / DEV badge so you never edit the wrong database
• Hide the Odoo.sh trial notice and the neutralised-database banner
• Enable the extension on localhost or internal domains, one address at a time

DEVELOPER TOOLS (optional)
• Script buttons: save JavaScript snippets as buttons and run them on the current tab in one click
• Automatic developer mode and one-click copy of technical field names
• Odoo.sh editor: odoo-bin shell and psql in the menu, zip / unzip, install and update modules from the file browser

PRIVATE BY DESIGN
• Every feature is off until you turn it on
• Settings are saved per domain, locally in your browser
• No tracking, no accounts, no external servers
